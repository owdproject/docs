The [same desktop engine](/architecture/overview) powers each integration. Choose based on the framework you want to use and how much tooling you need.

| Framework | What you can do today | Start with |
| --- | --- | --- |
| [Vue.js](/frameworks/vue) | Experimental: Vue 3 and Vite starter. | [`vue-desktop`](https://github.com/owdproject/vue-desktop) |
| [Nuxt.js](/frameworks/nuxt) | Use the full desktop starter, terminal UI, app and theme ecosystem, and extension playgrounds. OWD started on Nuxt, so this is the most mature path. | `npm create owd` → Nuxt |
| [React](/frameworks/react) | Run the early Vite starter with a shell and demo apps. | `npm create owd` → React |
| [Angular](/frameworks/angular) | Experimental: Angular starter with window streams and signals. | [`angular-desktop`](https://github.com/owdproject/angular-desktop) |
| [Astro](/frameworks/astro) | Experimental: Desktop window in a static Astro page. | [`astro-desktop`](https://github.com/owdproject/astro-desktop) |
| [Svelte](/frameworks/svelte) | Experimental: Svelte 5 starter backed by engine stores. | [`svelte-desktop`](https://github.com/owdproject/svelte-desktop) |

The [quickstart](/getting-started/installation) walks through the published starter picker for Nuxt.js and React. The four experimental starters use their own project scripts.

## Want to build out a framework?

A shell, a demo app, or a guide that takes someone from an empty folder to a running workspace can make an integration easier to adopt. See [Contribute a desktop or extension](/reference/contribute).
