The [React Desktop starter](https://github.com/owdproject/react-desktop) is an early scaffold with a Win95 shell and demo apps. [Create a React desktop](/getting-started/installation#react) to follow along.

## Find your way around

| File | Start here to… |
| --- | --- |
| `src/App.tsx` | See where the desktop instance is created and passed to the shell. |
| `src/apps/index.tsx` | Change the demo launcher menu or application registration. |
| `src/apps/` | Read the About and Notepad examples. |
| `package.json` | See the core and adapter versions and the shell's Git dependency. |

Use `pnpm dev` to run Vite, `pnpm build` to build the site, and `pnpm preview` to preview the production build. React projects use these scripts. The Nuxt control panel and extension scaffolds are specific to the Nuxt path.

See the [React adapter](https://github.com/owdproject/react) for React bindings and the [core overview](/architecture/overview) for shared runtime behavior.
