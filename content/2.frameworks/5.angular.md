title: Angular
description: Try an Angular desktop backed by engine streams and signals.
---

Angular Desktop is an experimental starter. **Open About** creates a window that you can drag, snap, resize and close.

Clone [`owdproject/angular-desktop`](https://github.com/owdproject/angular-desktop) to try it:

```bash
git clone https://github.com/owdproject/angular-desktop.git
cd angular-desktop/template
pnpm install --frozen-lockfile
pnpm dev
```

The [Angular adapter](https://github.com/owdproject/angular) supplies the window stream and pointer handlers, and the starter uses an Angular signal to render the window state.
