Vue Desktop is an experimental starter for a Vue 3 application. Vue components observe window snapshots through `shallowRef` and use the OWD core pointer APIs for drag, snap and resize.

Clone [`owdproject/vue-desktop`](https://github.com/owdproject/vue-desktop) to try the starter:

```bash
git clone https://github.com/owdproject/vue-desktop.git
cd vue-desktop/template
pnpm install --frozen-lockfile
pnpm dev
```

Open the URL shown by Vite and click **Open About**. Start with `src/Desktop.vue` to change the workspace and `src/DesktopWindow.vue` to change the window. The starter binds directly to the core, so it can run as a Vite app without a Nuxt host.

Want to build a launcher, shell or demo application? See [Contribute a desktop or extension](/reference/contribute).
