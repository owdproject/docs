---
title: Svelte
description: Try a Svelte 5 desktop using the engine's state through readable stores.
---

The Svelte experiment renders windows from a desktop store. Use **Open About** to create the example window, drag its title bar, or resize from the lower right corner.

Clone [`owdproject/svelte-desktop`](https://github.com/owdproject/svelte-desktop) to try the starter:

```bash
git clone https://github.com/owdproject/svelte-desktop.git
cd svelte-desktop/template
pnpm install --frozen-lockfile
pnpm dev
```

Start with `src/App.svelte` for desktop state and `src/DesktopWindow.svelte` for pointer interactions. The Vite starter uses an adapter source snapshot until the Svelte adapter is published. Use the [main quickstart](/getting-started/installation) for the currently available starter picker options.
