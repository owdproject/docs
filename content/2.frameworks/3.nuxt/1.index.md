Choose Nuxt for the desktop control panel and the most complete extension workflow. [Create a Nuxt desktop](/getting-started/installation#nuxt) to follow along.

## Make it yours

Open `desktop/desktop.config.ts` in the generated project. The starter uses Nuxt UI for the shell and includes the About app and a filesystem module.

```ts
import { defineDesktopConfig } from '@owdproject/nuxt'

export default defineDesktopConfig({
  theme: '@owdproject/nuxt-theme-ui',
  apps: ['@owdproject/nuxt-app-about'],
  modules: ['@owdproject/nuxt-module-fs'],
})
```

Use `pnpm dev` to start the project directly, `pnpm desktop` to open its control panel, or `pnpm generate` for a static build. Use `pnpm desktop --help` to see commands and flags for the installed CLI.

## Build an extension

From the desktop workspace, run `pnpm desktop create app my-tool` or `pnpm desktop create module my-service`. Follow the generated contract and use the package's playground to develop it in isolation. Apps register user-facing behavior, modules add services, and themes provide the desktop shell. Official Nuxt extensions use the `@owdproject/nuxt-<kind>-<name>` convention.

- [Nuxt extension contract](https://github.com/owdproject/nuxt/blob/main/docs/extension-contract.md) for adapter APIs and registration rules.
- [Nuxt Desktop](https://github.com/owdproject/nuxt-desktop) for the starter layout, control panel and CLI reference.
- [OWD 3.x archive](/frameworks/nuxt/archive) for the previous Nuxt integration and migrations.

Extensions are bundled into the host and run with the page's privileges. Install extensions you trust.

For a map of the current contracts and the detailed chapters on how Nuxt desktops boot and work, see [How OWD works](/architecture/technical-reference).
