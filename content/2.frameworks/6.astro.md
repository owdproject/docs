---
title: Astro
description: Try an Astro page with a desktop window powered by a custom element.
---

The Astro experiment attaches a custom element to a shared desktop instance in a browser script. The page and About window content are rendered by Astro. Use **Open About** to create a window, then drag its title bar or close and reopen it.

Clone [`owdproject/astro-desktop`](https://github.com/owdproject/astro-desktop) to try the starter:

```bash
git clone https://github.com/owdproject/astro-desktop.git
cd astro-desktop/template
pnpm install --frozen-lockfile
pnpm dev
```

The entry point is `src/pages/index.astro`. It uses an adapter source snapshot until the Astro adapter is published. The experiment uses project scripts. The starter picker and control panel are covered in the [main quickstart](/getting-started/installation).
