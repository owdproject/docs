---
title: Run your first desktop
description: Start in an empty folder, pick a starter and run your desktop from the terminal.
---

Have Node.js, npm, pnpm and Git installed. The interactive control panel uses Go. Start in a new, empty folder and run the initializer from an interactive terminal.

```bash
mkdir my-desktop
cd my-desktop
npm create owd
```

## Nuxt

Choose **Nuxt** in the starter picker. The initializer creates the workspace, installs its dependencies and opens the terminal UI. Press **d** to start the dev server, then open the URL shown in the terminal.

Return to the control panel with `pnpm desktop` from your project folder. Use **1**, **2** and **3** to browse apps, modules and themes. Press **s** to apply queued changes or **q** to quit. To launch the server directly, run `pnpm dev`.

Continue with the [Nuxt guide](/frameworks/nuxt) to configure your shell and install your first app.

## React

Choose **React** in the same starter picker to create a Vite workspace. Once installation finishes, run `pnpm dev` and open the URL printed by Vite. The [React guide](/frameworks/react) shows where to change the shell and demo apps.

## Scripted setup

Pass a target folder and a framework when you want to skip the picker. For example:

```bash
npm create owd my-desktop -- --framework nuxt --skip-install --skip-ui
cd my-desktop
pnpm install
pnpm dev
```

Use `--framework react` for the React starter. Both starters currently use OWD 4.x prereleases. [Vue.js](/frameworks/vue), [Angular](/frameworks/angular), [Astro](/frameworks/astro) and [Svelte](/frameworks/svelte) are separate experiments with their own setup instructions.
