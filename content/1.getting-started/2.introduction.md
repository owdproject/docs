---
title: What is Open Web Desktop?
description: Learn what OWD provides and choose where to start.
---

Open Web Desktop gives web applications a desktop workspace. Think of a browser workspace where a launcher opens tools in movable windows and the user can arrange those tools side by side.

The TypeScript engine tracks windows, processes and workspaces. A framework adapter connects that state to your UI. The shell decides what users see and touch, from a window title bar to a launcher.

## Where to start

- **I want a running desktop.** Follow the [quickstart](/getting-started/installation), then open the guide for your framework.
- **I have a UI already.** Start with the [engine overview](/architecture/overview) and see what the core can manage for you.
- **I want to build a desktop app or shell.** Choose your [framework](/frameworks) before following a package or API example.

Nuxt has the fuller desktop tooling today. React has a Vite starter for exploring the model. Check the [framework guide](/frameworks) for the scope of each path.
