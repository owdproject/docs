| I want to… | Start here |
| --- | --- |
| Understand window or process behavior | [Core](/architecture/overview), the shared runtime |
| Connect the runtime to a UI | [Frameworks](/frameworks), the integration paths |
| Build and run a desktop | [Quickstart](/getting-started/installation), using a starter from a desktop distribution |
| Change how a desktop looks | Your framework's shell or theme guide |
| Install or develop an extension | Your framework's app or module conventions |
| Find source repositories | [Ecosystem](/reference/useful-links) |

A **distribution** is the runnable framework project and the source for its starter. An **adapter** is a library used by that project. The exact folder layout and configuration file are defined by the distribution. See the [Nuxt guide](/frameworks/nuxt) and the [React guide](/frameworks/react) for their layouts.
