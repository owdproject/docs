| Repository | What it owns |
| --- | --- |
| [Core](https://github.com/owdproject/core) | Engine and its behavioral contract |
| [Angular adapter](https://github.com/owdproject/angular) · [Astro adapter](https://github.com/owdproject/astro) · [Svelte adapter](https://github.com/owdproject/svelte) | Additional integration source repositories |
| [CLI](https://github.com/owdproject/cli) | Starter scaffolding and developer commands |
| [create-owd](https://github.com/owdproject/create-owd) | Project initializer |
| [Nuxt adapter](https://github.com/owdproject/nuxt) · [Nuxt Desktop](https://github.com/owdproject/nuxt-desktop) | Nuxt bindings, runnable host and starter |
| [React adapter](https://github.com/owdproject/react) · [React Desktop](https://github.com/owdproject/react-desktop) | React bindings and Vite starter |
| [Desktop Template](https://github.com/owdproject/desktop-template) | Shared scaffold for distribution maintainers |
| [Docs](https://github.com/owdproject/docs) | This documentation |

Discover community packages through the GitHub topics for [apps](https://github.com/topics/owd-apps), [themes](https://github.com/topics/owd-themes) and [modules](https://github.com/topics/owd-modules). Check the target framework and package version before adding one to your desktop.
