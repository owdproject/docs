---
title: Glossary
description: The terms used across OWD and its framework guides.
---

| Term | Meaning |
| --- | --- |
| Engine or core | Framework-independent TypeScript runtime that manages desktop state. |
| Adapter | Framework-specific library that exposes the engine to a host UI. |
| Host or desktop project | The runnable web application where the engine, shell and apps come together. |
| Distribution | Repository that provides a framework's desktop project and starter. |
| Shell | UI around the apps, including the launcher, taskbar and window controls. |
| Theme | Shell implementation or styling package, according to the host's conventions. |
| App | User-facing tool that can register windows, launch entries or commands. |
| Module | Optional extension that adds behavior or services to a host. |
| Kit | Shared UI or utilities for extensions that use the same framework or UI library. |
