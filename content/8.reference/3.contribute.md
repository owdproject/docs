---
title: Contribute a desktop or extension
description: Pick a small contribution that helps a framework grow its OWD ecosystem.
---

OWD began as a Nuxt.js project. Nuxt has a starter, a terminal UI, apps, themes and playgrounds because those pieces were built there first. Each framework can grow its own set of tools on top of the shared engine.

| If you work on… | A useful first contribution |
| --- | --- |
| Vue.js, Angular, Astro, or Svelte | Add a second app, turn the window styling into a reusable shell, or write a guide for integrating OWD into an existing project. |
| React | Build an app or theme against the Vite starter, or document how to use the adapter with a different shell. |
| Nuxt.js | Add an app, theme or module with a standalone playground, or improve a scaffold and its guide. |

Pick a [framework](/frameworks) and open a GitHub issue in its adapter or desktop repository when one exists. If you're proposing a new distribution or need help finding where work belongs, [open an issue in docs](https://github.com/owdproject/docs/issues/new). Include the smallest example that shows what you want to build, how to run it, and the OWD version it uses.

If the work changes a shared behavior such as window state or lifecycle, start with the [engine and adapter contracts](/architecture/technical-reference).
