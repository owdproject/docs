# Open Web Desktop documentation

This Docus site covers the framework-independent desktop engine, framework integrations and desktop starters. The content is written in English.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Use `pnpm generate` to build the static site for GitHub Pages.

Shared concepts live in Start here and Architecture. The How OWD works page links to current runtime contracts and the original detailed Nuxt internals. Framework-specific instructions live under Frameworks. The former integration guides are kept in the Nuxt archive, which covers OWD versions 3.x. See [the content audit](DOCS-AUDIT.md) for the rationale and maintenance sources.
